# Library

Library is everything this wallet unlocked. It does not follow the public catalog.

## What stays

A confirmed purchase writes an entitlement. That row is independent of the listing’s public status (`live`, `delisted`, `suspended`).

If a listing is reported, it can leave the catalog. Buyers who already paid can still open it from Library.

## Progress and reviews

On an unlocked listing you can mark it finished and save a rating from 1 to 5. Reviews are for listings, not bounties. One review per wallet per listing; saving again replaces it.

## Saved vs Library

| | Saved | Library |
|---|---|---|
| What it is | Bookmark | Entitlement after payment |
| NIM | None | Paid (or your own listing) |
| Survives delist | Yes, until you unsave | Yes |
